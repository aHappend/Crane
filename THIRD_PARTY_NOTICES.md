## Generated SET network metadata and cost measurements

`workloads/set_networks.json` contains graph/shape facts exported from compiled
upstream network objects. `experiments/reference_profiles/` contains measurements
generated by the upstream Polar intra-layer mapper. Their manifests identify
the pinned revision, source/bridge hashes, units and included/excluded costs.

`experiments/results/` archives our recorded experiment configurations, solver
outputs, native SET summaries and generated figures. The native baseline wrapper
changes only the clock-derived seed in an isolated temporary source copy; the
patch is recorded in each manifest. The upstream checkout is not modified or
bundled in full.

For these inputs and reference runs, cite Jingwei Cai, Yuchen Wei, Zuotong Wu,
Sen Peng and Kaisheng Ma, *Inter-layer Scheduling Space Definition and Exploration
for Tiled Accelerators*, ISCA 2023,
[DOI: 10.1145/3579371.3589048](https://doi.org/10.1145/3579371.3589048).
Upstream's README requests citation for academic use. Generated records do not
change any underlying third-party rights or grant a new upstream software license.
